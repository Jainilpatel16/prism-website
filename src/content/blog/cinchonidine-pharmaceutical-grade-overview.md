## **What is Cinchonidine?**

Cinchonidine is an alkaloid belonging to the quinoline group which is extracted from the bark of Cinchona species of trees. It is similar in structure to quinine and quinidine in that it is a cinchona alkaloid. Cinchodinine is a compound that has stereochemical characteristics, which are important for its usage as a chiral resolving agent in pharmaceutical development. It is used as the active pharmaceutical ingredient in the development of pharmaceutical and chemical compounds in the following applications; A chiral resolving agent or auxiliary; as an API precursor; a specialty compound for R&D purposes. It is because of these stereochemical qualities that cinchonidine has found use in a number of asymmetric synthesis methods and manufacturers use it to synthesize enantiomerically pure products.
